# Java OOP Fundamentals

A collection of Java programs written to explore and solidify core Object-Oriented Programming principles.

## Core Concepts Demonstrated
* **Abstraction:** Implementation of abstract classes and interfaces (e.g., `Abstractex.java`).
* **Encapsulation:** Data hiding and state management (e.g., `Bank.java`).
* **Polymorphism & Inheritance:** Method overriding, overloading, and foundational class hierarchies.

## Environment
* **Language:** Java
